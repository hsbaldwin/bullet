# BULLET — 허공을 가르는 한 발

탄환이 허공을 가로질러 표적에 꽂히는 순간을 즐기는 브라우저 사격 게임입니다.
빌드 없이 `index.html` 하나로 동작합니다. 파일을 브라우저로 열기만 하면 됩니다.

## 플레이 방법

| 동작 | 데스크톱 | 모바일 |
| --- | --- | --- |
| 조준 | 마우스 이동 (`↑`/`↓` 0.1° 미세조정, `Shift`+화살표 1°) | 화면 드래그 |
| 발사 | 클릭 또는 `Space` | 손을 떼면 발사 |
| 인트로/결과 넘기기 | 클릭 또는 `Space` | 탭 |
| 음소거 | `M` | 🔊 버튼 |

- 탄환은 **중력**으로 떨어지고 **바람**에 밀립니다. 총구 앞쪽 일부 탄도만 점선으로 미리 보입니다(스테이지가 오를수록 짧아짐).
- 스테이지마다 탄 3발. 명중하면 다음 스테이지로, 3발을 모두 놓치면 게임 오버입니다.
- 오른쪽 위 **망원뷰**의 하늘색 **예상 탄착 표시**(표적 안이면 초록색)와 왼쪽 아래 예상 탄착·도달 시간 안내를 보고 조준하세요.
- 빗나가면 몇 도를 올리거나 내려야 하는지 **힌트**가 나오고, 흰 점선으로 직전 탄도가 남습니다.

## 특징

- 발사 후 카메라가 탄환을 따라가고, 표적 근처에서 **슬로모션 + 레터박스** 연출
- 탄환 뒤로 공기를 가르는 충격파 링과 트레일
- 고정 스텝(1/240초) 탄도 물리 — 미리보기 점선과 실제 탄도가 정확히 일치
- 단계별 난이도: 거리 증가 → 바람(2스테이지~) → 높은 표적 → 움직이는 표적(4스테이지~) → 표적 축소
- 점수: 링 점수(1~10) × 10 + 거리 보너스, 첫 발 명중 ×1.5, 연속 원샷 추가 점수
- WebAudio로 합성한 효과음, 최고 기록 로컬 저장

# 고요 스냅 — `snap/index.html`

iPhone에서 가볍게 여는 ADHD 안정화 스냅 스크롤 게임입니다. 숏폼처럼 위로 넘기지만, **지금 칸을 끝내야 다음 칸이 생깁니다.**
마음을 가라앉히는 4칸 → 몸을 움직이는 1칸 → 미루던 일을 **2분만 시작**하는 2칸으로 이어집니다.

| 칸 | 하는 일 |
| --- | --- |
| 착지 | 원을 누르는 동안 들이쉬고, 떼면 내쉬기 × 3 |
| 리듬 | 천천히 모이는 물결에 맞춰 8번 탭 |
| 집중 | 느리게 떠다니는 점 위에 손가락을 9초 동안 올려두기 |
| 가만히 | 12초 동안 화면 만지지 않기 |
| 작은 행동 | 물 마시기 같은 2분짜리 행동 하고 버튼 꾹 누르기 |
| 한 가지 | 미루던 일 하나를 "첫 동작"으로 적기 |
| 시작 | 2분 타이머 (30초 뒤부터 일찍 끝내기 가능) |

- Safari에서 **공유 → 홈 화면에 추가**하면 앱처럼 전체 화면으로 열립니다.
- 연속 일수·누적 판 수는 기기에만 저장됩니다.
