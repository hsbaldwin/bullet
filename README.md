# BULLET Classic — 2D 탄도 사격

옆에서 보는 2D 사격 게임입니다. 탄환이 허공을 가로질러 표적에 꽂히는 순간을 즐깁니다.
빌드 없이 `index.html` 하나로 동작하며, 브라우저로 열면 바로 플레이할 수 있습니다.

> 이 브랜치(`classic`)는 2D 버전만 따로 관리합니다. 1인칭 메인 게임은 다른 브랜치에서 관리합니다.

## 플레이 방법

| 동작 | PC | 휴대폰 |
| --- | --- | --- |
| 조준 | 마우스 이동 (`↑`/`↓` 0.1° 미세조정, `Shift`+화살표 1°) | 화면 드래그 |
| 발사 | 클릭 또는 `Space` | **발사** 버튼 (손을 떼도 발사되지 않음) |
| 일시정지 | `P` / `Esc` | ⏸ 버튼 (앱·탭을 벗어나면 자동) |
| 인트로·결과 넘기기 | 클릭 또는 `Space` | 탭 |
| 음소거 | `M` | 🔊 버튼 |

- 모바일 첫 화면은 터치용 3줄 안내만 보여 줍니다.
- 탄환은 **중력**으로 떨어지고 **바람**에 밀립니다.
- 스테이지마다 탄 3발. 명중하면 다음 스테이지로, 3발을 모두 놓치면 게임 오버입니다.
- 4스테이지부터 표적이 위아래로 움직입니다.

## 조준 단서

- **망원뷰**(오른쪽 위): 하늘색 **예상 탄착 표시**, 표적 안이면 초록색
- **예상 탄착·도달 시간**(왼쪽 아래)과, 빗나가면 몇 도를 고치면 되는지 알려주는 **힌트**
- 직전 탄도(흰 점선), 총구 앞 탄도 미리보기
- **바람:** 25m마다 거리 표지 깃발, 표적 옆 깃발, 바람에 날리는 먼지, 세기 막대와 "바람 영향(탄착 몇 m)" 표시

## 특징

- 발사 후 카메라가 탄환을 따라가고, 표적 근처를 지나는 탄만 슬로모션 + 레터박스 연출
- 고정 스텝(1/240초) 탄도 물리 — 미리보기와 실제 탄도가 정확히 일치
- 점수: 링 점수(1~10) × 10 + 거리 보너스, 첫 발 명중 ×1.5, 연속 원샷 추가 점수
- **랭킹:** 이 기기에 저장되는 닉네임당 한 줄 랭킹
- **📤 결과 공유:** 클리어한 스테이지마다 맞힌 링 색(🟡🔴🔵⚫⚪), 실패는 ❌
- **🌐 언어:** 브라우저 언어에 따라 한국어/영어, 첫 화면 버튼이나 `?lang=ko`, `?lang=en`으로 변경
- WebAudio로 합성한 효과음

## 배포

GitHub Pages는 저장소당 한 브랜치만 공개할 수 있습니다. 이 브랜치를 따로 공개하려면
다른 저장소에 올리거나, 정적 호스팅(예: Netlify, Cloudflare Pages)에서 이 브랜치를 배포하세요.
공유 문구에는 지금 열려 있는 주소가 들어갑니다(`index.html`의 `shareUrl`로 고정할 수도 있습니다).

## 모바일 성능

- 패널의 배경 흐림(`backdrop-filter`)을 없앴습니다.
- **자동 해상도:** 프레임이 30ms 넘게(약 33fps 미만) 계속 느리면 렌더 해상도를 75%까지만 낮추고, 여유가 생기면 다시 올립니다. 항상 100%로 시작하며, 화면 배율은 최대 2.5배까지 씁니다.
- 제목·게임 오버 화면은 초당 10번만 그리고, 일시정지 중에는 그리기와 계산, 소리를 모두 멈춥니다.
- 측정(Chromium, Pixel 5 에뮬레이션, CPU 4배 감속, 조준 화면): 평균 37fps → 60fps.
