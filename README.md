# BULLET — 아이언 사이트 사격

확대 조준경 없이 가늠자와 가늠쇠로만 쏘는 1인칭 사격 게임입니다. 탄은 중력으로 떨어지고 옆바람에 밀립니다.
빌드 없이 `index.html` 하나로 동작하며, 브라우저로 열면 바로 플레이할 수 있습니다.
예전 옆에서 보는 2D 버전은 `classic.html`에 남아 있습니다(이 기기 랭킹만 사용).

## 플레이 방법

| 동작 | PC | 휴대폰 |
| --- | --- | --- |
| 조준 | 화면을 클릭하면 마우스로 조준 (`Esc`로 해제), 방향키 미세조정 | 화면 드래그 |
| 발사 | 클릭 또는 `Space` | **발사** 버튼 |
| 숨 참기 | `Shift`를 누르는 동안 | **숨 참기** 버튼을 누르는 동안 |
| 결과 넘기기 | 클릭 또는 `Space` | 탭 |
| 음소거 | `M` | 🔊 버튼 |

- 가늠쇠 끝이 조준점입니다. 먼 표적은 탄이 떨어지는 만큼 위를, 옆바람이 불면 바람 반대쪽을 겨눕니다.
- 숨을 참으면 조준 흔들림이 거의 사라지지만, 4초를 넘기면 숨이 차서 한동안 크게 흔들립니다.
- 숨을 참는 동안은 감도가 절반이 되어 미세 조준이 쉬워집니다.
- 첫 화면에서 **마우스(터치) 감도**(0.3~3배)와 **조준 떨림 보정**을 바꿀 수 있고, 설정은 이 기기에 저장됩니다.

### 조준 입력 처리

- 마우스·터치 이동량은 이벤트마다 바로 반영하지 않고 모아 두었다가, 매 프레임 그리기 직전에 한 번에 반영합니다.
- 화면과 발사에 쓰는 조준은 One Euro 필터로 목표 조준을 따라갑니다. 천천히 움직일 때는 계단 현상을 걸러 내고, 빠르게 돌릴 때는 거의 지연이 없습니다.
  측정: 느린 조준에서 화면이 멈칫하는 프레임 140개 중 88개 → 0개, 10° 빠른 플릭은 31ms(약 2프레임) 안에 95% 도달.
- 마우스 고정 시 운영체제 가속을 끈 원시 입력(`unadjustedMovement`)을 먼저 요청하고, 지원하면 `pointerrawupdate` 이벤트로 지연을 줄입니다.
- 마우스 고정 직후나 비정상적으로 큰 이동값(한 번에 250픽셀 초과)은 무시합니다.
- 스테이지마다 탄 3발. 명중하면 다음 스테이지로, 3발을 모두 놓치면 게임 오버입니다. 4스테이지부터 표적이 좌우로 움직입니다.
- 쏜 뒤에는 "빗나감: 왼쪽 1.4m · 아래 1.1m"처럼 탄착 위치를 알려줍니다.

## 특징

- 발사하면 카메라가 탄을 뒤에서 따라갑니다(명중권 탄은 약 1.1초, 그 외는 0.5초 안팎). 명중이나 아슬아슬한 탄만 슬로모션이고, 명중하면 표적을 클로즈업합니다.
- 총구 속도 400m/s, 고정 탄도 계산(1/600초 간격).
- 3D 라이브러리 없이 캔버스 2D로 원근 투영을 직접 그립니다.
- 점수: 링 점수(1~10) × 10 + 거리(m), 첫 발 명중 ×1.5, 연속 원샷 추가 점수.

## 🎖 성장 자산 (계급·탄피·병기고)

기록이 쌓일수록 게임 안의 자산이 늘어납니다. 현금으로 바꿀 수 없는 꾸미기 자산이라 점수와 랭킹에는 영향이 없습니다.

- **경험치와 계급:** 판이 끝나면 그 판의 점수만큼 경험치가 쌓입니다. 계급 n에서 n+1까지 `250 + 125×(n-1)` XP가 필요합니다.
- **탄피(게임 화폐):** 판마다 `점수÷20 + 클리어 스테이지×2 + 불스아이×5`를 받습니다. 통산 판 수·명중·불스아이·최고 스테이지도 기록됩니다.
- **병기고:** 탄피로 가늠쇠 점 색, 총몸 마감, 예광탄 색을 사서 장착합니다. 높은 계급이 필요한 아이템도 있습니다.
- **서버 검증:** 지급량은 서버가 점수 상한을 검사한 뒤 직접 계산하고, 구매·장착도 서버가 잔액·계급·보유 여부를 확인합니다. 같은 플레이어는 10초 안에 다시 기록할 수 없습니다.
- **기기 이전:** 병기고의 **기록 이전 코드**를 다른 기기에 입력하면 계급·탄피·아이템·랭킹 기록이 그대로 옮겨집니다. 비밀번호처럼 다뤄야 합니다.
- 서버가 없으면 같은 규칙으로 이 기기에만 저장됩니다.

> **업데이트 시 주의:** 성장 자산용 서버 함수가 추가되었습니다. Supabase **SQL Editor**에서 [`supabase/setup.sql`](supabase/setup.sql)을 다시 실행하세요. 기존 랭킹 기록은 유지됩니다.

## ⚡ 성능 부하를 줄이는 방법

- **미리 그려 두기:** 하늘·땅·태양·탄 빛의 그라디언트와 가늠자·가늠쇠·비네트는 화면 크기가 바뀔 때 한 번만 그려 두고, 매 프레임은 복사만 합니다.
- **자동 해상도:** 프레임이 느려지면 렌더 해상도를 단계적으로(최저 50%) 낮추고, 여유가 생기면 다시 올립니다. 코어 4개 이하나 메모리가 적은 기기는 75%로 시작합니다.
- **쉬는 화면:** 제목·결과·랭킹 화면에서는 배경을 1초에 한 번만 그리고, 다른 탭으로 가면 소리 엔진도 멈춥니다.
- **가벼운 HUD:** 패널의 배경 흐림 효과(매 프레임 다시 계산됨)를 없애고, 값이 바뀔 때만 화면 요소를 고칩니다.
- **상한:** 파티클 150개 상한, 저해상도 모드에서는 산·지면 선의 세밀도를 낮춥니다. "동작 줄이기" 설정이면 화면 흔들림과 섬광을 끕니다.
- 측정(CPU 6배 감속, 2배 고해상도 화면 에뮬레이션): 조준 중 12fps → 50~60fps, 메뉴 화면 메인 스레드 사용 117% → 18%.

## 🌍 세계 랭킹

- 게임 오버 화면에서 닉네임을 정해 기록을 올립니다. 랭킹은 **플레이어당 한 줄**이고, 다시 올리면 더 높은 점수일 때만 갱신됩니다.
- **국가는 자동:** 서버가 접속 IP로 국가를 정합니다(Cloudflare `cf-ipcountry` 헤더). 게임 화면에는 "접속 위치"로 표시됩니다.
- **중복 등록 방지**
  - 브라우저마다 비밀 토큰을 하나 만들어 "내 기록"의 주인을 확인합니다. 서버에는 토큰의 해시만 저장합니다.
  - 닉네임은 대소문자 구분 없이 한 사람만 쓸 수 있습니다.
  - 같은 IP에서는 하루에 새 플레이어를 3명까지만 만들 수 있습니다. IP는 비밀 salt를 섞은 해시로만 저장합니다.
  - 같은 판을 두 번 올릴 수 없고, 같은 플레이어는 10초 안에 다시 올릴 수 없습니다.
- **📤 결과 공유:** 클리어한 스테이지마다 맞힌 링 색(🟡 9~10, 🔴 7~8, 🔵 5~6, ⚫ 3~4, ⚪ 1~2)을, 실패한 스테이지는 ❌를 붙여 공유합니다.
  휴대폰에서는 공유 창이 열리고, PC에서는 클립보드에 복사됩니다.
- **🌐 언어:** 브라우저 언어가 한국어면 한국어, 그 밖에는 영어로 나옵니다. 첫 화면 오른쪽 위 버튼이나 `?lang=ko`, `?lang=en`으로 바꿀 수 있습니다.
- **링크 미리보기:** 카카오톡, X, 디스코드 등에 주소를 붙이면 `og.png` 이미지와 소개 문구가 뜹니다(공개 주소 기준).

서버를 연결하기 전에는 이 기기 안에서만 기록이 저장됩니다(닉네임당 한 줄).

> **업데이트 시 주의:** 랭킹 구조가 바뀌었습니다. Supabase **SQL Editor**에서 [`supabase/setup.sql`](supabase/setup.sql)을 다시 한 번 실행하세요.
> 이전 버전의 기록 테이블(`scores`)은 지우지 않고 남겨 두며, 새 랭킹(`players`)은 비어서 시작합니다.

### 서버 연결 (무료, 약 5분)

1. [supabase.com](https://supabase.com)에 가입하고 **New project**를 만듭니다. 지역은 플레이어가 많은 곳 근처를 고르세요.
2. 왼쪽 메뉴의 **SQL Editor**에서 [`supabase/setup.sql`](supabase/setup.sql) 내용을 전부 붙여 넣고 **Run**을 누릅니다.
3. **Project Settings → API Keys**(또는 Data API)에서 **Project URL**과 **공개 키**(`sb_publishable_…` 또는 `anon` key)를 복사합니다.
   `service_role`/`secret` 키는 절대 넣지 마세요.
4. `index.html` 위쪽의 `BULLET_CONFIG`에 두 값을 넣습니다.
   ```js
   window.BULLET_CONFIG = window.BULLET_CONFIG || {
     supabaseUrl: 'https://xxxx.supabase.co',
     supabaseAnonKey: 'sb_publishable_xxxx',
   };
   ```
   공개 키는 브라우저에 노출되도록 만들어진 키라서 저장소에 올려도 됩니다. 데이터는 아래 규칙으로 보호됩니다.

### 게임을 인터넷에 공개 (GitHub Pages)

저장소의 **Settings → Pages → Build and deployment**에서 Source를 **Deploy from a branch**로, 브랜치를 게임이 있는 브랜치와 `/ (root)`로 정하고 저장합니다.
1~2분 뒤 `https://<사용자명>.github.io/bullet/` 주소로 누구나 접속해 플레이할 수 있습니다.

### 서버의 보호 규칙

- 테이블은 API로 직접 읽거나 쓸 수 없고, `submit_score` / `my_entry` / `top_scores` 함수로만 접근합니다.
- 닉네임은 1~16자로 공백을 정리합니다.
- 도달한 스테이지로 낼 수 있는 최대 점수를 넘는 기록은 거부합니다.
- 게임이 브라우저에서 돌아가므로, 개발자 도구를 다루는 사람은 상한 이하의 가짜 점수를 보낼 수 있습니다.
  브라우저 데이터를 지우면 새 토큰이 생겨 다른 플레이어로 다시 등록할 수 있지만, 같은 IP에서는 하루 3명으로 제한됩니다.
  이상한 기록은 Supabase **Table Editor → players**에서 지우면 됩니다.
